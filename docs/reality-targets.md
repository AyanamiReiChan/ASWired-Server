# REALITY 目标池与扫描

目标池仅管理员可查看和管理，包括列表、手动添加、扫描、导入、探测、审核与允许列表。普通用户及其 API Token 无权访问；不再提供成员贡献入口。已有目标、探测历史和历史贡献记录保留。目标须经实际探测和审核后才能启用。扫描由主控发起，网络延迟反映主控到目标的链路，不代表 Agent 所在服务器的线路质量。

## 批量扫描

管理员调用 `POST /api/reality-targets/scan`，请求为 `{"targets":"example.com:443\n8.8.8.0/30"}`。空字符串使用内置的少量公开域名种子。输入支持逗号、空白、换行分隔的域名、IP、可选端口，以及 IPv4/IPv6 CIDR；未指定端口使用 443，IPv6 带端口使用 `[地址]:端口`。

输入展开最多 128 个地址，每个 CIDR 最多 128 个地址；超过范围会拒绝整批，重复输入也占展开额度，实际重复目标只探测一次。每批最多 16 个并发，每个目标共用 8 秒时限（包括 IP 的 SNI 发现和复探），整批最长 65 秒。同一主控实例同时只允许一个批次；请求取消或主控关闭会取消扫描，未完成批次不保存证据。

生产拨号使用公网地址检查，先检查全部 DNS 返回值，再对确定的 IP 建立连接。私网、回环、链路本地、多播和已列明的保留网段被拒绝。探测不发送 HTTP 请求、账户凭据或业务配置。

可用结果必须实际协商 TLS 1.3、h2、X25519，且证书通过系统根信任链、有效期、服务器用途和 SNI 域名校验。客户端只提供 X25519 密钥交换，结果同时检查握手返回的 CurveID。`certChainBytes` 是服务端实际发送的证书 DER 总字节数，不是估算值。

IP 目标先不发送 SNI，从返回证书中提取具体 DNS SAN 域名，然后使用该域名作为 SNI，再次连接**原 IP 和原端口**。只有复探通过的域名可导入；不将通配符或证书 CN 猜测为可用域名。

响应包含 `scanId`、`expiresAt`、`source: "controller"`、`results`、`total`、`feasibleCount`。每项结果包含：

- `id`、`target`（原始目的地址及端口）、`host`（探测 SNI）、`ip`、`port`。
- `feasible`、`tls13`、`h2`、`x25519`、`certValid`、`certChainValid`、`certChainBytes`。
- `serverNames`、`alpn`、`tlsVersion`、`curveID`、`certificateExpires`、`certSubject`、`certIssuer`、`checkedAt`。
- `latencyMs`、`tcpMs`、`handshakeMs` 是该次结果握手的实际耗时；IP 发现成功后显示最终确认握手的耗时。`reason` 保留失败原因，失败的检查不会标为通过。

扫描证据绑定发起管理员，保存 15 分钟。新扫描会清理已过期证据，同一主控最多保留 64 个尚未过期批次；达到上限返回 429，等待旧证据过期后可继续。

## 导入与审核

管理员调用 `POST /api/reality-targets/scan/import`，请求为 `{"scanId":"服务端返回值","resultIds":["结果ID"]}`。接口不接收客户端提交的探测结果、可用标记或自选 SNI；只读取本人发起、未过期且通过所有检查的服务端证据。

选中目标与已保存目标按目的地址（包含端口）和 SNI 域名去重。新域名加入允许列表，新目标保存为 `pending`、`enabled: false` 并携带实际探测证据，仍须执行既有审核操作。允许列表最多 200 个域名；允许列表与目标记录在同一事务中保存，失败不会部分导入。响应为 `{"rows":[],"imported":0,"skipped":0}`，`rows` 只包含新建记录。

重复目标直接跳过，不恢复已撤销的允许域名。为新目的地址重新加入一个此前撤销的域名时，该域名旧目标保持不可用：事务将旧记录的启用标记设为 false，保留其审核状态和探测历史，须另行启用或审核。

导入目标的后续单条探测继续使用保存的原目的地址和端口，以及确认的 SNI 域名。手动添加接口仅管理员可用，只接受允许列表中的具体域名，端口固定为 443。目标仍须通过实际探测和审核，才能启用。

## 验证

`reality_scan_test.go` 使用本地受控 TLS 服务验证协议、h2、X25519、信任链、域名、有效期和 IP/SNI 复探；并覆盖权限、输入上限、公网限制、证据过期与篡改、原子导入、撤销域名、并发上限和取消。测试不修改运行中的数据库或用户服务器。

`reality_pool_permissions_test.go` 覆盖普通账户（含创建满七天的账户）的 JWT 与 API Token 拒绝、内部集合与 MCP 隔离，以及拒绝请求不改变目标、扫描证据、允许列表或历史贡献额度。
